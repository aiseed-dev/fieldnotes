# ストーリー

（2026-10-28 確定。README、デモ動画、提出文はこの筋に合わせる）

今の農業は、肥料を外から買い、使い方も農協や業者の指導に頼る形で回ってきました。会社が情報システムを業者とMicrosoftに預けてきたのと同じです。リン鉱石は埋蔵量の約7割がモロッコに集まり、中国は2021年からリン肥料の輸出を絞っています。安く安定して買える時代が終わりつつある中で、外に頼る形はそのまま弱点になります。

変え方も同じです。外から買う物を減らし、自分の畑の中の力、つまり根と菌根菌でリンを回す形に作り直す。ただ、畑ごとに土も草も違うので、一つのやり方を上から配ることはできません。そこでAIが、それぞれの畑の地形、地質、草、天気を読んで、その畑に合った刈り方と作物を出す。人は畑を見て、手を動かし、結果で答え合わせをする。

外に頼る形のもう一つの結果が、耕作放棄地です。担い手がいなくなった畑は草に戻り、全国で約42万ha、富山県とほぼ同じ広さになっています。けれど草に戻る力は、土の力でもあります。私の畑は無肥料にして4年目ですが、1年草を刈らずにおいたら、人の背丈を超えるセイタカアワダチソウとオギの原になりました。外から何も入れなくても、土はこれだけのものを育てます。この畑の土はミネラルが豊富です。足りないのは、植物が自分で取れる仕組み（根と菌根菌）です。この道具は、そういう土地を読み、どこからどう刈って作物に戻すかを出すところまで含めます。

土にあるものを根と菌根菌で回すやり方は、国も業者も教えてくれません。SaaSなら業者が使い方を教えてくれますが、OSSは自分で勉強するしかないのと同じです。それでもOSSが成り立つのは、中身を読めて、学んだことが記録として共有され、今はAIが読むのを手伝ってくれるからです。畑でも同じことができます。

Metaのハッカソンで作ろうとしているのは、まさにその道具です。農家一人一人が、業者や指導を通さずに自分の畑を読めるようになる。AIネイティブな情報システム部門と同じことを、畑でやる形です。

ただ、育てるだけでは続きません。最大の課題は販売です。売り方も、農協と市場に預けてきました。今の流通は形と量がそろうことを前提にしていて、どんな畑でどう育てたかは買い手に届きません。自然農業の販売を支えてくれる人もいません。だから自然農業は、流通から自分で作る必要があります。この道具が残す記録、つまり畑の土と草、手入れ、育ち、そして農家が一つずつ確かめた答え合わせは、まず自分の栽培の土台であり、そのまま買い手の信頼の土台にもなります。

## ストーリーと、ハッカソンで作るものの対応

| ストーリーの言葉 | 作るもの |
|---|---|
| 畑の地形、地質 | `records/site.md`（国土地理院の標高、地質図、土壌図。出典付き） |
| 天気 | `weather.py`（Open-Meteo、畑の座標の日別値） |
| 草 | 定期的な定点写真 → SAM 3.1 で草・作物・裸地を切り分け、被覆率に |
| 読む | Muse Spark が今日と過去の写真を比べ、まず畑全体の様子を言い、次に変化を書く。分からなければ「不明」と言う |
| 人は畑を見て、結果で答え合わせ | 農家が畑で声で話す → Voice Transcribe → AI の各項目に正誤 |
| その畑に合った | AI と一緒に定期的に観察し、「何をしたら、どう変わったか」という改善の方法の知識がこの畑についてたまる。訂正は次の観察のプロンプトに戻る |
| 業者や指導を通さずに | 記録は手元のプレーンテキスト。Glimmer で自宅のマシンだけでも動く |
| 耕作放棄地を復活させる | 3つ目の定点（無肥料4年目、1年刈らずにおいた区画。放棄地と同じ姿）。刈る前の草の構成を記録し、刈った後の戻り方を追う |
| 刈り方と作物を出す | 作物の側は**緑肥の混植の提案**（`propose.py`）。記録から組み合わせ・まき方・確かめ方を出し、農家が結果で答え合わせ。刈り方は下の「刈り方の提案」 |

## 根拠（数字の出典）

- リン鉱石の埋蔵量: 世界 約740億 t のうちモロッコ（西サハラを含む）約500億 t。— USGS Mineral Commodity Summaries 2024, Phosphate Rock
- 中国の輸出制限: 2021年10月からリン肥料の輸出に検査証明を義務付け、以後は輸出枠で絞っている。
- リン鉱石の「枯渇」について（2026-10-28 調べ）:
  - Cordell ら（2009）は、リン生産のピークを 2033 年頃と予測した。ところが 2010 年に北西アフリカの埋蔵量が 57 億 t から 510 億 t に見直され、「すぐ枯渇する」という話は多くの論文で争われている。
  - 2026 年の USGS では、世界の埋蔵量 約 730 億 t、2025 年の採掘量 約 2.5 億 t。単純に割ると約 290 年分。
  - だから**話の芯は「枯渇」ではなく「偏在・輸出規制・価格高騰・輸入依存」**に置く。ストーリー本文はすでにそうなっている。動画でも「枯渇」とは言わない。
  — USGS MCS 2026 Phosphate https://pubs.usgs.gov/periodicals/mcs2026/mcs2026-phosphate.pdf ／Earth Syst. Dynam. 5, 491 (2014) https://esd.copernicus.org/articles/5/491/2014/esd-5-491-2014.pdf
- 耕作放棄地 約42.3万ha: 2015年農林業センサス（この項目を取った最後の回）。富山県の面積は約42.5万ha。

## 注意（審査で突かれうる点）

- **大根もカイランもアブラナ科で、菌根菌と共生しない。** 菌根の網を保つのは草のほう。だから「草を抜かずに刈る、根を残す」ことが次の作物のためになる、という筋で話す。1つ目の定点の作物を菌根の例に使わない。
- このハッカソンの9日間で見せられるのは「読む」と「答え合わせ」まで。リンが回っていることは9日では測れないので、言わない。
- この区画は本当の放棄地ではなく、自分の畑を1年刈らずにおいたもの。動画では「放棄地と同じ姿になった区画」と正直に言う。むしろ「1年でここまで戻る」ことが話の材料になる。
- 放棄地も9日では「復活」しない。見せられるのは「刈る前の読み」と「刈った直後の数日の変化」。復活はハッカソン後も続く記録として語る。

## 刈り方の提案（[F]、放棄地で使う）

ストーリーの山場は「その畑に合った刈り方と作物を出す」。放棄地はこれを見せるのにいちばん合う場所になる。

1. 刈る前に、SAM で草の種類ごとの被覆率を出す（セイタカアワダチソウ、オギなど）。
2. site.md（地形・地質・この区画の来歴）＋天気＋被覆率から、Spark に**最初にどこを、どの高さで刈るか**を一つ出させる。理由も書かせる。
3. 農家が刈る（または提案を却下して理由を言う）。
4. 刈った後の数日の写真で、何が先に戻ってくるかを記録し、提案の答え合わせをする。

作るなら 11/1 以降、B〜D が動いてから。
