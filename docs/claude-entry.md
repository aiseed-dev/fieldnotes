# Built with Claude: Japan 2026 の成果物の概要

（計画担当の下書き、2026-10-31。農家の決めたことだけを書き、決まっていない所はそう書く）

## 一行で

自然農法の農家が、自分の畑の記録から、自分の理論を作る道具。観察は Meta のハッカソンで作った fieldnotes が受け持ち、こちらは「なぜそうなったか」を記録から問う側を新しく作る。

## 出発点

応募文に書いた二つの機能のうち、後半の「理論の構築」。

> 蓄積した記録を Claude に読ませ、なぜそうなったのかの仮説を本人と一緒に立てる。根拠には海外の研究と福岡正信の著作を優先して使い、出典と確認日を付け、推測で書かせない。仮説を確かめるために次に何を観察すればよいかを決めて、観察に戻る。本人が納得した仮説だけを自分の理論として蓄積する。

理論の出発点はりん酸。肥料を外から買う形は、りん鉱石の偏在と輸出規制と価格で弱点になる。自然農法は肥料を入れず、土にある物を根と菌で回す作り方で、それが本当に起きているかを自分の畑の記録で確かめていく。（応募文の数字は、使う時に出典と確認日を付ける。）

## 誰のための物か

指導者のいない自然農法の人。農協や業者の指導は肥料と決まった品種を前提にしていて、肥料を入れない畑に何が合うかは誰も教えてくれない。最初の使い手は農家自身。石井町の畑（無肥料 4 年目）と、新居浜の畑が最初の二つの土地。

## 期間中に新しく始めること

- **種と混植の記録。** 一つの場所と、そこにまいた一つの混合を一枚の記録にする。種類ごとに種の出どころ・量・割合、まき方、覆い、日付、その時の土の読み。その後は種類ごとに、出た・伸びた・覆われた・食われた・花・収穫・採種の行。種類どうしの関係の行。最後に「この土地でこの混合から残ったのは何か」の判断の行。
- **種の考え方。** 交雑を認める。種は品種でなく「ある場所で、ある年に採った種」の単位で追い、親はその場所に一緒に生えていた物。買った最初の種だけ袋の名前を出どころとして残す。
- **根拠の規則。** 種苗会社の品種説明は根拠にしない。この土地に合う種の根拠は、自分たちの栽培記録だけ。記録が無ければ「まだ無い」と書く。
- **理論の構築。** 記録（fieldnotes の文字の記録と、新しい種の記録）を Claude が読み、仮説を出典と確認日付きで出し、本人が納得した物だけが理論の文書に積もる。次に何を観察するかを決めて、観察に戻す。

まくのは、この季節に合うそら豆とえんどうと、10-31 の混合。収穫の場面は、別の人の畑から（本人の了解を文字で）。販売は無理に入れない。

## Claude の使い方

- 理論の構築は Claude のエージェント。道具は、記録を読む、似た土地の記録を土・地形・気候で探す、仮説を出典付きで書く、次の観察を決める、本人の ✓ を記録に戻す。
- 農家は畑で声で話し、Claude が記録の枠に直し、農家が ✓ を付ける。
- 作るのは全部 Claude Code。設計書と利用者マニュアルを先に書き、設計書どおりに実装する（aiai と同じ順序）。

## fieldnotes（Meta 側）との線

- fieldnotes は畑を読む側。来歴と土壌、草と野菜から見た土の状態を、出典付きの文字にする。写真を読むのは fieldnotes だけ。
- こちらは fieldnotes の文字の記録を入力として受け取る。fieldnotes の expect.md（土地の資料から出す区画ごとの予想）は書かず、その答え合わせの結果を読んで「なぜ」を問う。
- fieldnotes を PyPI に公開した版（`fieldnotes-farm`、11-02 12:00 より前）に依存する形を候補にしている。主催者に文字で確かめる。
- 物語（docs/story.md の最初の二段落）は両方で同じ。分かれ目は「刈り方と作物」。

## 動画で見せる物と見せない物

見せる: 期間中に始めた記録の最初の行（10-31 と 11-01 にまいた物）、日ごとの出芽の行（入れば）、記録から Claude が出した仮説と出典、本人の ✓、次の観察。別の人の収穫の行。

見せない: fieldnotes の画面と機能。注文の場面。採種（数か月先。空の列に予定だけ）。「輪の全部でなく一周目の一週間」と最初に言う。

## 規則との対応

- 新規制作のみ: 新しいリポジトリを 11-02 12:00 以降に作り、fieldnotes のコードは入れない。
- 提出: 11-08（日）20:00 JST。概要、3 分の動画、公開リポジトリ、すべて日本語。
- 審査: インパクト 30 / デモ 25 / Claude の活用 25 / 深さと実行 20。
- 避ける例: 画像解析ツール（Meta 側に置く）、アドバイザー型のチャット（記録と ✓ と次の観察という動く部分を中心に置く）。

## 決まっていないこと

- テーマ。1「あなたにしかない深さを」（自分の畑から自分の理論を作る）か、2「本来、誰にでも届くべきものを」（指導者のいない自然農法の人が、その土地に合う種を選べるようにする）。
- 記録の枠（上の「種と混植の記録」）の確定。
- PyPI 公開と、主催者の答え。
- プロジェクトの名前。
